# DSA 全面反思与升级方案（2026-08-18）

> **修订记录（2026-08-18 晚，诊断完成后）**：本文档最初基于"保守化漂移"假设。经 8 项对抗性诊断（含强势股实测、兆易创新底部回放、量价工具排查），假设大幅修正——详见文末「九、诊断修订」。**P0 三项已实施**。

> 原始背景：回测数据显示 7-8 月观望建议占比 100%，零买入建议。但 long 建议的股票平均上涨 +5.36%，提示判断力与表达之间可能存在落差。

## 二、根因分析（五个）

### 根因 1：风险信号不对称堆积

近期接入的数据（forecast/fina_indicator/margin/PE 分位/5 日 10 日资金流）全部以"风险警报"形式呈现。每份报告风险清单 7-8 条 vs 利好 3-4 条。LLM 面对这个不对称比例，理性选择永远是谨慎。**数据越全，风险清单越长；机会清单没有对称增长。**

### 根因 2：RiskAgent 否决权不对称

`risk_override.py:241`：RiskAgent high → buy 转 hold（或 hold→sell 降一档）。降级只需"中等风险"，升级需要"多重确认"。**单向棘轮结构，系统天然向保守漂移。**

### 根因 3：观望无成本

回测只惩罚说错的方向，不惩罚"该说买时没说"。cash 建议期间股票涨 +5% 无任何机会成本记录。LLM（与整个评估体系）学到的隐含教训：犹豫最安全。

### 根因 4：大盘护栏无解除机制

Daily Market Context 在大盘弱时单向软化 buy→观望，但大盘强（如 8/17 半导体 +4.85%、3700 家上涨）时**没有对称的进攻解锁**。护栏变成单向阀门。

### 根因 5：量价关系分析缺失，LLM 靠幻觉补位

现状盘点（`stock_analyzer.py:_analyze_volume`，仅 30 行）：

```
当日量 ÷ 5日均量 = 量比 → 四象限标签（放量上涨/放量下跌/缩量上涨/缩量回调）+ 量能正常
```

仅此一个维度。缺失的关键能力：

| 缺失 | 实战价值 | 证据 |
|------|---------|------|
| 阳量阴量比（吸筹/派发） | 最直接的筹码动向指标 | 长江证券报告中 LLM 自己推"下跌日均量大于上涨日呈派发"——裸推无数据 |
| OBV 能量潮+背离 | 顶/底背离经典信号 | 完全没有 |
| 量价相关系数 | 量价配合度量化 | 特变电工问股 LLM 报"相关系数 0.17"——**纯幻觉，无工具计算过** |
| 地量/天量分位 | 变盘前兆，"地量见地价" | 完全没有 |
| 量价形态区分 | 高位放量出货 vs 低位放量启动，同样涨停意义相反 | 8/17 通富微电涨停日主力净流出 1.58 亿，系统无框架区分 |
| 关键位量能验证 | 支撑缩量企稳/阻力放量通过 | 完全没有 |

**LLM 在量价这块最需要算术支撑的领域裸奔，只能编数字。** 这是"数据越多 LLM 越保守"的微观机制之一：复杂原始数据 + 无结构化结论 = LLM 只能挑最安全的说法。

## 三、改造方案：三层架构

核心思想：**让 AI 干 AI 擅长的事**。LLM 擅长定性推理（新闻解读、逻辑链、矛盾识别），不擅长定量择时与算术。现在 DSA 的架构恰好相反——LLM 做最终择时，规则做数据准备。

```
┌─────────────────────────────────────────────────────┐
│ 第一层：规则化信号引擎（无 LLM，确定性）              │
│                                                     │
│  A. 量价结构分析（VolumeAnalyzer，新建）              │
│     量能分位 / 阳量阴量比 / OBV 背离 / 量价形态 /    │
│     关键位量能验证                                   │
│  B. 市场情绪周期（SentimentCycle，新建）              │
│     涨停数 / 连板高度 / 炸板率 / 涨跌家数 / 昨日涨停  │
│     今日表现 → 冰点/回暖/发酵/高潮/退潮 五态          │
│  C. 均线结构（已有 analyze_trend，复用）              │
│                                                     │
│  输出：客观状态机（不输出买卖建议）                    │
├─────────────────────────────────────────────────────┤
│ 第二层：LLM 定性研判（现有 Agent 链，调整职责）        │
│                                                     │
│  新闻事件解读 / 板块轮动逻辑 / 基本面叙事 /           │
│  多源矛盾识别 / 事件影响幅度估计                      │
│                                                     │
│  输出：方向观点 + 置信度（不再直接输出操作建议）       │
├─────────────────────────────────────────────────────┤
│ 第三层：规则化决策合成器（无 LLM，新建）              │
│                                                     │
│  第一层周期状态 × 第二层 LLM 观点 → 最终建议          │
│  冰点期：看多观点权重 ×1.5（对抗 LLM 保守偏差）       │
│  高潮期：看多观点权重 ×0.5（对抗追热偏差）            │
│  量价形态作为升级/降级的硬依据（双向）                 │
│                                                     │
│  输出：操作建议 + 仓位 + 止损 + 建议理由链            │
└─────────────────────────────────────────────────────┘
```

### 3.1 A：VolumeAnalyzer（量价结构分析）

**位置**：`src/services/volume_analyzer.py`（新建）

**输入**：日线 OHLCV（`get_daily_data` 已有，250 日）

**五个维度**：

```python
@dataclass
class VolumeAnalysis:
    # 1. 量能分位：当日成交量在近 250 日的百分位
    volume_percentile: float          # 0-100
    volume_regime: str                # 地量(<10)/缩量(<30)/正常/放量(>70)/天量(>90)

    # 2. 阳量阴量比：近 20 日上涨日均量 / 下跌日均量
    bull_bear_volume_ratio: float     # >1.3 吸筹 / <0.75 派发 / 中性
    accumulation_signal: str          # 吸筹/派发/中性

    # 3. OBV 趋势与背离
    obv_slope_20d: float              # OBV 20 日斜率
    obv_divergence: str               # 顶背离/底背离/同向/无明显

    # 4. 量价形态（规则树）
    volume_price_pattern: str         # 放量突破/放量滞涨/缩量洗盘/
                                      # 无量阴跌/天量见顶/地量筑底/普通

    # 5. 关键位量能验证
    support_volume_check: str         # 支撑位缩量企稳/放量跌破/未触及
    resistance_volume_check: str      # 阻力位放量通过/缩量受阻/未触及
```

**量价形态规则树**（核心逻辑）：

| 形态 | 判定规则 | 含义 |
|------|---------|------|
| 放量突破 | 量 > 2×5日均量 + 收盘涨 > 2% + 突破 20 日高点/阻力位 | 强势信号，升级依据 |
| 放量滞涨 | 量 > 2×5日均量 + 收盘涨幅 < 1% 或长上影 > 2% | 出货嫌疑，降级依据 |
| 缩量洗盘 | 缩量 < 0.7 均量 + 跌幅 < 3% + 守住 MA10/支撑 | 良性回调，持有依据 |
| 无量阴跌 | 连续 5 日缩量阴跌 | 抛压未尽，规避 |
| 天量见顶 | 量分位 > 90 + 高位（距 60 日高点 < 5%）+ 收阴 | 顶部信号，降级依据 |
| 地量筑底 | 量分位 < 10 + 低位（距 60 日低点 < 10%）+ 横盘 10 日+ | 底部酝酿，左侧关注 |

**关键位量能验证**（配合现有支撑压力位）：
- 支撑位缩量企稳（回调至支撑 + 量 < 0.7 均量 + 收盘站上支撑）→ 买点确认
- 阻力位放量通过（触及阻力 + 量 > 1.5 均量 + 收盘越过阻力）→ 突破确认
- 阻力位缩量回落（触及阻力 + 量 < 0.7 均量 + 收盘回落）→ 假突破风险

**注入路径**：格式化文本注入 `news_context`（踩坑记录：enhanced_context LLM 不可见，必须走 news_context，与 forecast/fina 注入同路径）。

### 3.2 B：SentimentCycle（市场情绪周期）

**位置**：`src/services/sentiment_cycle.py`（新建）

**数据**：涨跌家数（大盘复盘已有）、涨停/跌停数、连板高度、炸板率（需新增数据源，Tushare `limit_list_d` 5000 积分可用或 kpl 接口）

**五态状态机**（借鉴游资情绪周期理论 + QuantsPlaybook 研报思路）：

| 状态 | 判定（示例） | 对第三层的调制 |
|------|------------|---------------|
| 冰点 | 涨停 < 30 且炸板率 > 40% 且连板高度 ≤ 2 | 看多观点 ×1.5，左侧机会加分 |
| 回暖 | 涨停回升 + 昨涨停今表现转正 | 看多观点 ×1.2 |
| 发酵 | 涨停 50-80 + 连板高度 4-6 | 看多观点 ×1.0（中性） |
| 高潮 | 涨停 > 100 + 连板高度 ≥ 7 | 看多观点 ×0.5，防追高 |
| 退潮 | 昨涨停今表现 < -3% + 跌停增多 | 看多观点 ×0.7，防守 |

具体阈值待用历史数据校准（QuantsPlaybook 有现成复现代码可参考）。

### 3.3 C：第三层决策合成器

**位置**：`src/agent/decision_composer.py`（新建，替代/前置现有 risk_override）

**输入**：
1. LLM 观点（方向 + 置信度 + 理由）——从现有 Agent 链输出提取
2. VolumeAnalyzer 结构化信号
3. SentimentCycle 状态
4. 均线结构（已有）

**合成规则（示例）**：

```python
# 情绪调制
weight = {冰点:1.5, 回暖:1.2, 发酵:1.0, 高潮:0.5, 退潮:0.7}[cycle]
adjusted_score = llm_score * weight

# 量价硬规则（双向，替代单向 risk_override）
if pattern == 放量突破: adjusted_score += 10
if pattern == 天量见顶: adjusted_score -= 15
if pattern == 地量筑底 and cycle == 冰点: adjusted_score += 12   # 左侧机会
if accumulation == 派发: adjusted_score -= 8
if support_volume_check == 支撑缩量企稳: adjusted_score += 8

# 映射建议
score >= 70 → 买入/加仓
55-69 → 持有
40-54 → 观望
< 40 → 减仓/卖出
```

**关键改进**：降级和升级使用同一套硬依据，消除单向棘轮。

### 3.4 报告分离"观点"与"建议"

报告新增字段，把被压制的判断力显性化：

```
📈 方向观点：看多（信心 70%）—— 基本面预增 80-90% + 缩量回踩 MA5 企稳
🎭 情绪周期：退潮期（看多观点权重 ×0.7）
📊 量价形态：缩量洗盘（良性）
💡 综合建议：观望（观点看多，但退潮期+量能未确认，等待发酵信号）
```

用户能看到"系统其实看好，只是环境不对"，而不是只看到一个被压平的 39 分。

## 四、回测改进（配套）

### 4.1 观望计分（missed opportunity）

`backtest_engine` 新增：cash 建议期间股价涨幅也记录。

- cash 建议期间涨幅 > +5% → 记 `missed_bull`（错失机会）
- cash 建议期间涨幅 < -5% → 记 `correct_avoid`（成功规避）
- 汇总指标：**机会成本率 = missed_bull / total_cash**，直接量化保守化的代价

### 4.2 分组统计上线

按情绪周期分组统计胜率——验证"冰点期看多胜率更高"假设，为 3.2 的调制系数提供校准依据。

## 六、风险与边界

1. **不追求激进**：目标是消除"结构性保守"（该敢不敢），不是变成追涨系统。冰点期×1.5 的上限就是"敢给左侧机会"，高潮期×0.5 保证不追热。
2. **调制系数需校准**：3.2 的五态阈值与 3.3 的权重是初始假设，P2-1 用数据校准后固化。
3. **不破坏现有兼容**：三层架构通过 news_context 注入 + decision_composer 前置实现，短线 pipeline 主流程不动。
4. **量价形态规则树需防过拟合**：每个形态规则保持简单可解释（不超过 3 个条件），宁可漏判不可误判。

### 9.2 被砍掉/降级的原设计

- ❌ "LLM 只出观点不出点位"——用户质疑正确：新代推理模型算力足够，且 DSA 的 LLM 定价质量本就不差。撤回。

- ❌ VolumeAnalyzer 新建——工具已存在（analysis_tools.py:234），只需接线。
- ⏸️ SentimentCycle 情绪周期——诊断未直接支持，暂缓，待 P0 效果评估后再议。

### 9.3 P0 实施记录（2026-08-18，已完成）
