# 中长线趋势分析模块设计方案

> 阶段一：方案设计文档。覆盖架构、数据源映射、评分模型、Agent 角色定义、与短线模块的边界。

## 1. 定位与边界

### 1.1 为什么独立而非合并

短线和长线的决策逻辑本质不同：

- **短线**（DSA 现有）：赚市场情绪和资金流动的钱。核心看量比、换手、MA5/10/20 金叉死叉、当日资金流向。决策频率日级别。
- **中长线**（本模块）：赚企业成长和趋势延续的钱。核心看 ROE 趋势、营收增速、估值分位、MA60/120 方向。决策频率周级别。

如果把两套逻辑塞进同一个 prompt，LLM 会被矛盾信号干扰——短线说"放量突破买入"，长线说"估值偏高等待回踩"，输出变成四不像。因此本模块是**完全独立的分析链**，独立入口、独立 prompt、独立评分体系，不修改短线 pipeline 任何代码。

### 1.2 持仓周期与服务定位

| 维度 | 短线 DSA | 中长线模块 |
|------|---------|-----------|
| 持仓周期 | 1-5 个交易日 | 2 周 - 3 个月 |
| 决策频率 | 每日盘前/盘后 | 每周末或触发式 |
| 均线体系 | MA5/10/20 | MA20/60/120 |
| 核心信号 | 量比、换手、乖离率 | ROE 趋势、营收增速、估值分位 |
| 止损逻辑 | MA20 下方（-5%~-8%） | MA60 减仓 / MA120 清仓 |
| 评分权重 | 技术 45% + 基本面 20% | 基本面 40% + 趋势 30% + 行业 15% + 风险 15% |
| 选股 | 无 | 全市场扫描 |

### 1.3 功能范围

1. **选股引擎**——规则化打分全市场扫描，不依赖 LLM，快速迭代
2. **个股深度分析**——多空辩论 + 基本面三表，LLM 驱动
3. **持仓监控**（后续阶段）——持仓股定期巡检 + 趋势跟踪止损

### 2.2 数据源策略

**优先级：Tushare > akshare > 其他**

中长线模块的数据全部优先走 Tushare 5000 积分接口，因为：

1. **稳定性**：Tushare Pro 是商业级 API，SLA 远高于免费爬虫
2. **历史深度**：fina_indicator 可查 10+ 年财务数据，akshare 难以做到
3. **一致性**：同一数据源，字段定义统一，避免拼接偏差
4. **已有基建**：DSA 的 `tushare_fetcher.py` 已经封装了调用链

akshare 仅在以下场景兜底：
- 实时行情（Tushare quotation 接口延迟）
- 股东户数（Tushare 5000 不可用）
- 板块实时涨跌（Tushare 无当日板块行情）

### 2.3 频率限制注意事项

Tushare 部分接口有频率限制（如 `report_rc` 1 次/分钟），在选股全市场扫描时需要：
- 串行调用 + sleep 控频
- 缓存结果到本地（财务数据季度更新，无需重复拉取）
- 选股引擎只做粗筛（用 `daily_basic` + `fina_indicator`），深度接口（三表/研报）仅在个股分析时调用

## 3. 选股引擎设计

### 3.1 设计理念

借鉴 stock-selector 的三维评分思路，但权重和阈值针对中长线重新设计。选股引擎是**纯规则化打分**，不依赖 LLM，确保速度和可解释性。

### 3.2 三层筛选流程

```
全市场 ~5000 只 → [第一层：硬性过滤] → ~800 只 → [第二层：趋势筛选] → ~200 只 → [第三层：评分排序] → Top 20-50
```

#### 第一层：硬性过滤（排除不可投资标的）

| 条件 | 数据源 | 说明 |
|------|--------|------|
| 排除 ST/*ST | `stock_basic` name 字段 | 基本面风险 |
| 排除退市 | `stock_basic` delisted | 流动性风险 |
| 排除上市<1 年 | `stock_basic` list_date | 缺乏历史数据 |
| 排除 PE<0 或 PE>100 | `daily_basic` | 亏损或估值泡沫 |
| 排除 PB<0 | `daily_basic` | 资不抵债 |
| 最近 ROE > 5% | `fina_indicator` | 最低盈利门槛 |

#### 第二层：趋势筛选（MA60/120 多头）

| 条件 | 数据源 | 说明 |
|------|--------|------|
| 收盘价 > MA60 | `daily` 计算 | 中期趋势向上 |
| MA20 > MA60 | `daily` 计算 | 均线多头排列 |
| MA60 斜率向上 | `daily` 计算 | 趋势在加速而非减速 |

#### 第三层：综合评分（100 分制）

| 维度 | 权重 | 满分 | 评分要素 |
|------|------|------|---------|
| **盈利质量** | 30 分 | 30 | ROE（10）、毛利率（8）、净利率（6）、ROE 趋势（6） |
| **成长性** | 25 分 | 25 | 营收增速（10）、净利增速（10）、增速加速度（5） |
| **估值安全** | 20 分 | 20 | PE 分位（8）、PB 分位（6）、PEG（6） |
| **趋势强度** | 15 分 | 15 | MA 多头程度（8）、价格位置（4）、成交量趋势（3） |
| **筹码与资金** | 10 分 | 10 | 北向持股变化（4）、股东增持（3）、机构调研（3） |

### 3.3 评分实现方式

所有评分用 Python 规则化计算，不调 LLM：

```python
# 伪代码示例
def score_quality(fina_data: dict) -> dict:
    """盈利质量评分 (30分)"""
    score = 0
    details = {}

    roe = fina_data.get("roe", 0)
    if roe >= 20: score += 10
    elif roe >= 15: score += 8
    elif roe >= 10: score += 6
    elif roe >= 5: score += 3
    details["roe"] = f"{roe:.1f}% → {10 if roe>=20 else 8 if roe>=15 else 6 if roe>=10 else 3}分"

    # ROE 趋势：近4季度是否上升
    roe_trend = check_roe_trend(fina_data["roe_history"])
    if roe_trend == "up": score += 6
    details["roe_trend"] = roe_trend

    # ... 毛利率、净利率同理
    return {"score": score, "details": details}
```

### 4.1 Agent 架构（借鉴 TradingAgents，适配 A 股）

│  │ 基本面 Agent │  │ 趋势 Agent  │  │ 风控 Agent  │                 │
│  │  (三表分析)  │  │ (MA60/120)  │  │ (五维排查)  │                 │
│  └──────┬─────┘  └──────┬─────┘  └──────┬─────┘                 │
│         │               │               │                        │
│         └───────────────┼───────────────┘                        │

│              ┌─────────────────────┐                             │

### 4.2 Agent 角色定义

#### 基本面 Agent（Fundamental Analyst）

**数据工具**（全部 Tushare 5000）：
- `get_income_statement`：利润表（营收/净利润/毛利率，近 8 个季度）
- `get_balance_sheet`：资产负债表（资产负债率/商誉/应收/货币资金）
- `get_cashflow_statement`：现金流量表（经营/投资/筹资 CF）
- `get_fina_indicator`：ROE/ROA/净利率/速动比率 + 历史趋势
- `get_forecast`：业绩预告
- `get_dividend`：分红历史与股息率

**分析框架**：
1. 盈利能力：ROE 绝对值 + 趋势（连续 4 季度方向）
2. 成长性：营收增速 + 净利增速 + 增速是否加速
3. 财务健康：资产负债率、速动比率、经营现金流/净利润比
4. 盈利质量：现金流 vs 净利润匹配度，商誉占比
5. 分红回报：股息率、分红率稳定性

**输出**：基本面评分（0-100）+ 3 个核心亮点 + 3 个核心风险

#### 趋势 Agent（Trend Analyst）

**数据工具**：
- `get_daily_history`：日线数据（计算 MA20/60/120、周线、MACD）
- `get_daily_basic`：PE/PB 历史分位
- `get_cyq_perf`：筹码分布

**分析框架**：
1. 大趋势：MA60 方向（上升/走平/下降）、MA120 方向
2. 位置：当前价格在 MA60/MA120 之上还是之下，乖离率
3. 均线关系：MA20 vs MA60 vs MA120 排列（多头/空头/缠绕）
4. 估值区间：PE/PB 近 3 年分位（<30% 低估，>70% 高估）
5. 筹码结构：获利盘比例、集中度

**输出**：趋势评分（0-100）+ 趋势阶段判断（底部/上升/顶部/下降）+ 理想买入区间

#### 风控 Agent（Risk Analyst）

**数据工具**：
- `get_share_float`：限售解禁（未来 3 个月是否有解禁压力）
- `get_stk_holdertrade`：股东增减持（近 30 天方向）
- `get_repurchase`：回购（进度、金额）
- `get_disclosure_date`：财报披露日期（是否临近）
- `get_fina_audit`：审计意见（是否非标）

**分析框架**（五维排查）：
1. 解禁风险：未来 3 个月解禁市值 / 流通市值 > 10% → 高风险
2. 减持风险：重要股东近 30 天净减持 > 5000 万 → 负面信号
3. 财报风险：临近财报披露 + 业绩预告预减 → 预警
4. 审计风险：非标审计意见 → 一票否决
5. 商誉风险：商誉 / 净资产 > 30% → 减值风险

**输出**：风险等级（低/中/高）+ 具体风险点列表

#### 多头研究员（Bull Researcher）

读取三个 Agent 的报告，构建看多论据：
- 基本面改善证据（ROE 回升、增速加速）
- 趋势确认证据（MA60 上行、估值低位）
- 催化剂（回购、业绩预告、行业政策）

#### 空头研究员（Bear Researcher）

读取同一批数据，构建看空论据：
- 基本面隐患（现金流差、应收高、商誉风险）
- 趋势风险（MA60 走平、估值高位）
- 潜在利空（解禁、减持、行业周期拐点）

#### 投资经理（Investment Manager）

综合多空辩论，输出最终决策：

```json
{
  "ticker": "600089",
  "name": "特变电工",

  "confidence": "中",
  "timeframe": "1-3个月",
  "fundamental_score": 72,
  "trend_score": 68,
  "risk_level": "中",
  "bull_case": "...",
  "bear_case": "...",
  "verdict": "...",
  "action_plan": {
    "entry_zone": "20.0-20.5",
    "add_zone": "19.5-20.0",

    "target_1": "23.0 (MA60)",
    "target_2": "26.0 (前高)",

  }

```

### 4.3 与短线 DSA 的 Agent 对比

| 维度 | 短线 DSA Agent | 中长线 Agent |
|------|---------------|-------------|
| 数据深度 | MA5/10/20 + 量比 + 换手 | 三表 + ROE 10 年趋势 + MA60/120 |
| 分析视角 | 当日量价 + 短期资金 | 季度基本面 + 中期趋势 |
| 辩论机制 | 无 | 多空辩论 |
| 评分权重 | 技术 45% | 基本面 40% |
| 持仓建议 | 1-3 天 | 2 周 - 3 月 |
| 止损依据 | MA20（-5%~-8%） | MA60/MA120（-10%~-15%） |
